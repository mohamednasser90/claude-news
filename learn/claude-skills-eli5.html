Claude Skills, Explained Like You're 5

Big pictures, few words. Read one section a day.

1. What is a Skill?

A recipe card for Claude.

No card = Claude guesses. With a card = Claude follows your steps.

2. What is inside a Skill?

One folder. One main file.

---
name: pancake-helper
description: Make pancakes. Use when the user asks for pancakes or breakfast cakes.
---

1. Mix flour, egg, milk.
2. Heat the pan.
3. Pour small circles. Flip when bubbles pop.
Two lines matter most: name and description. They are the label on the box.

3. How does Claude pick the right Skill?

It reads all the labels first. It opens a box only when needed.

Tip: A vague description = the box never gets opened. Say when to use it.

4. Commands: the buttons you press

A command is a word starting with / that you type in Claude Code.

A skill can be a command too. If its folder is eli5, you type /eli5.

5. Useful built-in commands

Type /help to see the full list on your machine.

6. Plugin = a toolbox

A plugin is a box with many skills and tools inside.

Install one plugin = get all its pieces at once.

7. Marketplace = a shop of toolboxes

The community shop has about 2,284 plugins.

/plugin marketplace add anthropics/claude-plugins-community
/plugin install eli5@claude-community

8. Make your first Skill (5 steps)

  • Make a folder: .claude/skills/my-first/
  • Add a file SKILL.md inside it.
  • Write the label: name and a clear description.
  • Write 3 to 5 simple steps under it.
  • Ask Claude something that matches your description. Watch it use the card.
Practice idea: make a skill called summarize-notes that turns messy notes into 3 bullet points.

10. Quick self-check

Tick what you can explain. Come back when you can't.

Good habits

Read a skill before you install it. Skills can run code and change files.
Keep one job per skill. Small boxes are easy to open.
Move long details into references/. Keep the main card short.
Made for learning. Command lists change over time, so check /help on your machine.
